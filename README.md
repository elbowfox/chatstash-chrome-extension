# ChatStash - AI Chat Organizer

Chrome extension to save and organize chats from ChatGPT, Claude, Gemini, Grok into folders.

## Free tier: 3 folders
## Pro: unlimited (LemonSqueezy license key)

### Setup
1. Clone or download.
2. Edit popup.js: set BUY_URL to your LemonSqueezy checkout.
3. Load unpacked in chrome://extensions.
4. For store: pay $5 Chrome Web Store fee, publish.

Pricing suggestion: $4.99/mo or $29 lifetime.

Realistic revenue: depends heavily on marketing; $0-800/mo first year typical for niche tools.
